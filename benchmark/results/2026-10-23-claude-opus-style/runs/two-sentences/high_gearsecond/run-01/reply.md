Rust's borrow checker enforces "aliasing XOR mutability": a value can have either any number of shared references or exactly one mutable reference at a time, so the compiler can prove no two pieces of code can modify (or read while another modifies) the same memory simultaneously. This prevents data races and related aliasing bugs, such as iterator invalidation and use-after-free when one reference reallocates or frees memory another still points to, at compile time with no runtime cost.
