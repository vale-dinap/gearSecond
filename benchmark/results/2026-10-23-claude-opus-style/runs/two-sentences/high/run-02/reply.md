Rust's borrow checker enforces "aliasing XOR mutability": at any moment a value can have either many shared `&T` references or exactly one `&mut T`, so the compiler can prove that no other path can observe or change the data while it's being mutated. This rules out data races between threads, and within a single thread it also prevents aliasing bugs like iterator invalidation and use-after-free, where one reference reallocates or frees memory that another reference still points to.
