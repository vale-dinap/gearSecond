Rust's borrow checker enforces "aliasing XOR mutability": a value can have many shared `&T` references or exactly one `&mut T` at a time. This lets the compiler guarantee that no one else can observe or change data while it's being mutated. That rules out data races, plus single-threaded aliasing bugs like iterator invalidation and use-after-free from a reallocated buffer, all at compile time with no runtime cost.
