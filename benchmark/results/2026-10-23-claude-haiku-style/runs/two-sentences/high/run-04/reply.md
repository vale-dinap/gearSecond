Rust's borrow checker enforces that a value has either any number of shared references or exactly one mutable reference at a time, because if two mutable paths could alter the same data while the other is still live, the result depends on aliasing and ordering that the compiler can't reason about safely. This rule prevents data races and iterator invalidation bugs, where one alias changes or frees memory (such as a `Vec`'s buffer on reallocation) out from under another that still expects it to be valid.
